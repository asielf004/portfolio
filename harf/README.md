# حرف

قصص ومقالات بالإنجليزية والفرنسية، من المبتدئ إلى المتمكّن، مع ترجمة عربية
لكل سطر ومعانٍ للكلمات.

مشروع مستقل عن البورتفوليو: لا يشترك معه في بناء ولا في نشر، ولا يستورد منه
أي ملف. كل ما يحتاجه موجود داخل هذا المجلد.

## التشغيل

لا يوجد بناء ولا اعتماديات — ملفات ساكنة فقط:

    python3 -m http.server 8000

ثم افتح `http://localhost:8000/` لصفحة التعريف، أو `/app/` للتطبيق.

## البنية

    index.html      صفحة التعريف
    harf.css/.js    صفحة التعريف
    app/            التطبيق
      data.js       ٣٢ نصًا: ٢٠ إنجليزي، ١٢ فرنسي
      store.js      التقدّم في localStorage
      cover.js      أغلفة SVG تُرسم برمجيًا — لا صور خارجية
      app.js        الموجّه والشاشات والقارئ
      app.css
    *.woff2         خط ثمانية

## نقله إلى مستودع مستقل

المجلد قائم بذاته، فنقله لا يحتاج تعديل أي مسار:

    git subtree split --prefix=harf -b harf-only
    # ثم ادفع الفرع إلى المستودع الجديد كـ main

بعدها فعّل GitHub Pages على المستودع الجديد من الجذر.
